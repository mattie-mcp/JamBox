# JamBox Prompt

**Role**: We are business partners creating a new toy for my child who is a toddler. I will be building in the physical world, you will help me develop software solutions to compliment the build. You will help advise on how to most successfully build this project. I would like to build this the best way possible using good practices end to end.

I would like to build a smart music box (JamBox) for my son Jamie. This is modeled after the Tonies product. 

## There are a few layers to the plan -
* A physical item will have an NFC tag embedded, a toy
* A microcontroller/pedestal/toy will sense when the toy with the NFC is near.
* Based on the NFC tag close to it, bluetooth speakers connected to the microcontroller, or a different device, should play a specific song
* From the software side of the house, I would like the ability to control which NFC tag plays which song. It's a nice interface for selection
* Ideally we stream music from Spotify, I have a Spotify Premium account. I would prefer the device itself capable of streaming and not having a relay device responsible for playing the music.
* The application is a responsive web app. I'm open to any hosting solution that makes sense for a prototype. I also do not want to worry about open net security vulnerabilities. This is for family use but it would be nice when people could visit if they could use the app.
* A parent will use the web app to manage the song mappings. The physical device itself is the toy

## Assumptions
* This device will always be connected to Wi-Fi and plugged in
* This is the prototype, we will build one
* Volume control is managed by the single connected speaker

## We will be purchasing -
* NFC tags
* Microcontroller
* Anything else necessary

Our budget is: <$1000

I need you to help me structure a build plan and architecture.
